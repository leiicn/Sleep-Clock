# Sleep Clock

床頭夜鐘網頁版：純黑背景、超大「時:分」（不顯示秒）、日期與星期小字。

- 點按畫面開啟設定：亮度、顏色（暗白／紅／琥珀）、12 小時制、六種語言、五種字體、螢幕方向（自動／強制豎屏／強制橫屏）
- 防燒屏：數字每分鐘輕微移位；支援保持螢幕開啟（Wake Lock）與全螢幕
- 在 iPhone／iPad 用 Safari 開啟 GitHub Pages 網址，選「加入主畫面」即可全屏使用

A fullscreen bedside night clock for iPhone and iPad. Open the GitHub Pages URL in Safari and choose "Add to Home Screen".
